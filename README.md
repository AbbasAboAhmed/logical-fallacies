# رحلتي في المغالطات المنطقية

## إزاي تفتحه
افتح رابط الموقع، أو نزّل الريبو ودبل كليك على `index.html`.
الموقع شرح لكتاب «المغالطات المنطقية: فصول في المنطق غير الصوري» لعادل مصطفى. الكتاب نفسه مش موجود هنا؛ كل فصل بيقولك رقم صفحته في الكتاب.
التقدم والملاحظات بيتحفظوا في المتصفح نفسه. من صفحة «حفظ بياناتي» تقدر تاخد نسخة (JSON) وترجّعها.

## الملفات
- `index.html`: هيكل الموقع.
- `assets/app.js` و `assets/styles.css`: الشكل والتفاعل.
- `assets/sheets/`: أوراق المراجعة (الإنفوجرافيك) للفصول 1–12.
- `assets/fonts/`: خط Cairo (رخصة SIL OFL).
- `content/_index.js`: قائمة الـ 35 فصل (الرقم، الاسم، الاسم الإنجليزي، صفحة الكتاب).
- `content/00-intro.js`: المقدمة.
- `content/01.js` … `35.js`: كل فصل في ملف لوحده.

## تعدّل فصل
افتح ملف الفصل (مثلًا `content/09.js`) وعدّل النص اللي جوه علامات التنصيص. احفظ الملف بـ UTF-8.
أجزاء كل فصل بالترتيب:
`opening` (الموقف)، `definition` (تعريف الكتاب)، `mechanism` (الخطوات)، `diagram` (الرسم)،
`bookExamples` (أمثلة الكتاب)، `examples` (أمثلة للتوضيح)، `why` (ليه بتقنع)، `boundary` (إمتى مش مغالطة)،
`comparison` (المقارنة)، `detection` (أسئلة الكشف)، `response` (الرد والتجنب)، `summary` (الملخص)،
`memory` (بطاقة الحفظ)، `practice` (3 مواقف للتطبيق).

## تضيف فصل جديد
1. انسخ أي ملف فصل لملف جديد وعدّل محتواه.
2. أضف سطر `<script src="content/XX.js"></script>` في `index.html` قبل سطر `assets/app.js`.
3. أضف الفصل في `content/_index.js`.
